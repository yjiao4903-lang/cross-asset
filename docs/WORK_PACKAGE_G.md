# 工作包 G：本周主线与持仓腿

状态 `DEVELOPMENT_PRIOR`。解决的是周报仍像六资产填空，不是再加一套区制标签。

## 为什么这一刀

卖方 / CIO 周报先写一句话主线：本周最大的价格事实是什么、哪条腿在做自己的工作、为什么仍然不行动。
Bridgewater All Weather 的用法在这里只借「每条资产有环境工作」，不借风险平价，也不改战略权重。

## 交付

- `weekly_story.py` 按一周幅度排序六条腿，选出一条会变的主线。
- 六条腿写成工作描述：A股=国内增长风险，港股=离岸中国，美股=全球风险，国债=国内久期，黄金=避险/财政残差，铜=工业周期。
- digest 开头改成主线，六条数字退到备查。
- `build_weekly_layers` 把主线接在四格前面。
- 默认仍不行动。

## 不做

- 不爬新闻、不加 Risk-On 仓、不加优化器
- 不把 FRED / Wind 升格为 RESEARCH_ADMISSIBLE
- 不合并到 `main`（仍须 #57 → #58 → #59 → 本分支）
